# ランダムポケモン

ボタンを押すと、ランダムなポケモン（全国図鑑 No.1〜1025）を表示する静的サイトです。
データは [PokeAPI](https://pokeapi.co/docs/v2) から取得しています。

- 日本語名・分類・タイプ・たかさ/おもさ・種族値・図鑑説明を表示
- 先頭タイプの色で背景が変化
- スペースキーでも表示可能

## ローカルで見る

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

## 公開

Vercel に静的サイトとしてデプロイしています。
